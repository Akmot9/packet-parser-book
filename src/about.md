# About

`packet_parser` and this book are written by Cyprien Avico ([LinkedIn](https://www.linkedin.com/in/cyprien-avico)).

- The repository of the crate: [Akmot9/Packet-parser](https://github.com/Akmot9/Packet-parser)
- The crate: [crates.io, packet_parser](https://crates.io/crates/packet_parser)
- The API reference: [docs.rs, packet_parser](https://docs.rs/packet_parser)

The API reference says what each item is. This book says how the crate reads a packet, and why it reads it that way.

Corrections are welcome, as an issue or a pull request on the repository of the book.
